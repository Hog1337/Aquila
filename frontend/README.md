# Wallcreepers ReID — фронтенд

Vite + React 18. Экраны: Поиск, Галерея, Метрики и порог, История, Экспорт; окно «Grad-CAM» открывается из блока сравнения (фактически показывает карту CLS-attention, см. [`../docs/backend.md`](../docs/backend.md#64-grad-cam-get-queriesidcandidatesrankgradcam)). Кадр запроса можно загрузить кнопкой, перетащить на область кадра или вставить из буфера (Ctrl+V); на «Поиске» есть флажок «Re-ranking (QE)».

```bash
npm install
npm run dev      # разработка
npm run build    # сборка в dist/ (index.html + assets/ с шрифтами)
```

Образ frontend собирает и выкатывает корневой пайплайн решения (`../Jenkinsfile`, деплой на aquila через `../run.sh --registry`), отдельного пайплайна у фронтенда нет. Отдельно из этого каталога: `docker compose up --build` (образ собирается из `Dockerfile`, пакеты скачиваются с npm registry).

Состояние экранов (открытый экран в hash адреса, фильтры, рамка, результат поиска, черновик порога, кадр запроса) переживает перезагрузку страницы; что и где хранится: [`../docs/frontend.md`, раздел 3.2](../docs/frontend.md#32-не-из-api-локально-в-браузере).

Встроенных данных нет: всё приходит из API `/api/v1` (клиент `src/lib/api.js`), контракт и описание экранов в [`../docs/frontend.md`](../docs/frontend.md). Без backend экраны показывают пустые состояния. Тема оформления одна: тёмная «Сталь» (токены в начале `src/styles.css`), переключателя тем нет.
