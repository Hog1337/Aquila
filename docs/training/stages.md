# Этапы обучения

Обучение проходило в 5 последовательных этапов. Каждый этап — отдельный
скрипт, который продолжает обучение с чекпоинта предыдущего этапа.

---

## Этап 0: Warm-start (VeRi-776)

**Скрипт:** `verid/scripts/` (отдельный проект)
**Чекпоинт:** `LLRD6b_best.pt`

Перед основным обучением модель была прогрета на датасете **VeRi-776**
(37 746 изображений, 575 ID) с архитектурой:
- LoRA rank 16, alpha 32
- AttnPoolHead (1 query, последний слой ViT, 512d)
- Разморожены блоки 16–23

Этот чекпоинт используется как стартовая точка для Этапа 1.

---

## Этап 1: Joint DN-ReID + Falcon (CE baseline)

**Скрипт:** [`training/baseline/joint_dn_falcon.py`](../training/baseline/joint_dn_falcon.py)

| Параметр | Значение |
|----------|----------|
| Чекпоинт | `LLRD6b_best.pt` |
| Датасеты | Falcon + DN-ReID |
| Голова | OptionC Head (6 queries, слои [16,18,20,22,23,24], LayerNorm, 512d) |
| Потери | CE (label smoothing 0.1) |
| LoRA | rank 16, alpha 32 |
| Блоки | 16–23 (8 блоков, дифференцированный LR) |
| P×K | 16×4 = 64/шаг |
| Микс датасетов | Falcon 30%, DN 70% |
| Эпох | 30 |
| LR | LoRA=3e-5, Head=3e-4, Blocks=2.5e-6…2e-5 |
| Scheduler | Linear warmup 3ep + Cosine decay |
| EMA | **Нет** (EMA введён на Этапе 4) |
| **Результат** | **mAP@10 = 0.741** |

**Ключевое изменение:** замена головы с AttnPoolHead (1 query, последний слой)
на OptionC Head (6 queries, 6 слоёв, LayerNorm).

---

## Этап 2: +Supervised Contrastive Loss

**Скрипт:** [`training/baseline/joint_supcon.py`](../training/baseline/joint_supcon.py)

| Параметр | Значение |
|----------|----------|
| Чекпоинт | `LLRD6b_best.pt` |
| Изменение | Добавлен SupCon Loss (λ=0.3, T=0.07) |
| Потери | CE + 0.3·SupCon |
| Эпох | 40 |
| **Результат** | **mAP@10 = 0.754** (+0.013) |

**Суть:** к CE добавлен supervised contrastive loss, который стягивает
эмбеддинги одного класса и раздвигает разных. Работает на батче (P=16, K=4).

---

## Этап 3: +BNNeck + Prototype Contrastive

**Скрипт:** [`training/baseline/joint_bnneck_proto.py`](../training/baseline/joint_bnneck_proto.py)

| Параметр | Значение |
|----------|----------|
| Чекпоинт | `LLRD6b_best.pt` |
| Изменение | BNNeck (BatchNorm перед CE) + ProtoCon Loss (λ=0.15) |
| Потери | CE(через BN) + 0.3·SupCon + 0.15·ProtoCon |
| ProtoBank | Momentum=0.99 |
| Эпох | 40 |
| **Результат** | **mAP@10 = 0.774** (+0.020) |

**BNNeck:** BatchNorm1d ставится перед CE-классификатором. Это разделяет
пространства для CE (через BN) и метрических лоссов (до BN).

**ProtoCon:** каждый класс представлен прототипом (ema-усреднение эмбеддингов),
anchor сравнивается со своим прототипом (позитив) и со всеми чужими (негатив).
Работает как cross-batch contrastive.

## Этап 4: +VeRI-Wild, LoRA rank 32, 2048d

**Скрипт:** [`training/baseline/joint_triple.py`](../training/baseline/joint_triple.py)

| Параметр | Значение |
|----------|----------|
| Чекпоинт | `LLRD6b_best.pt` (queries только для инициализации головы) |
| Датасеты | Falcon + DN-ReID + **VeRI-Wild** |
| LoRA | rank **32** (было 16), alpha **64** (было 32) |
| Проекция | **2048d** (было 512) |
| Голова | HeadBNNeck, слои **[0,4,8,12,16,20]**, **без LayerNorm** |
| Блоки | **14–23** (10 блоков, было 16–23) |
| Аугментации | RandomHorizontalFlip(p=0.5), ColorJitter |
| Микс датасетов | Falcon 25%, DN 35%, VeRI-Wild 40% |
| Эпох | 30, 600 шагов/эпоха |
| EMA | decay=0.999 |
| **Online mAP** | **0.8109** |
| **EMA mAP** | **0.8431** 🚀 (+0.069 к Этапу 3) |

**Ключевые изменения:**
- **VeRI-Wild** — главный буст (+0.069 mAP). Крупнейший датасет (277k изображений,
  30k ID) дал модели увидеть огромное разнообразие автомобилей
- **LoRA rank 32** — больше адаптивных параметров
- **2048d** — более ёмкое представление
- **Слои головы [0,4,8,12,16,20]** — ранние слои дают геометрические фичи,
  поздние — семантические; комбинация оказалась лучше, чем только поздние
- **Больше размороженных блоков (14–23 vs 16–23)**
- **Аугментации** — флипы и цветовые искажения для регуляризации
- **EMA** — стабилизирует веса, даёт +0.032 mAP

## Этап 5: Masked Fine-tune

**Скрипт:** [`training/baseline/joint_masked_ft.py`](../training/baseline/joint_masked_ft.py)

| Параметр | Значение |
|----------|----------|
| Чекпоинт | `JDNFV_SUPCON_PROTO_R32_best_ema.pt` (результат Этапа 4) |
| Датасеты | Falcon (маскированные кропы) + DN-ReID |
| Изображения | `images_clean/` (предобработаны: YOLO-маски, удаление фона) |
| Метки | Чистые (после clean_dataset.py) |
| LoRA | rank 32, alpha 64 (без изменений) |
| Потери | CE + 0.3·SupCon + 0.15·ProtoCon |
| Эпох | 10 |
| LR | 5e-6 (уменьшен) |
| Сэмплинг | Cross-View Hard Sampler (по разным камерам внутри класса) |
| **Результат** | **mAP@10 = 0.839** (финальный) |

**Суть этапа:** модель дообучается на кропах, где **чужие машины удалены**
через YOLO11s-seg. Это убирает шум из фона и заставляет модель фокусироваться
на целевом автомобиле. Дополнительно применяется Cross-View Hard Sampler —
внутри батча подбираются снимки одной машины с разных камер, чтобы усилить
инвариантность к ракурсу.
